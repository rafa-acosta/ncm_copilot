### [control_00004] TACACS — HIGH

Status: NON-COMPLIANT
Reference: VibeCoding controls.yaml v6f92236

Risk Statement: Failure to communicate with central security servers forces the use of local accounts, making user management difficult and less secure across the network.
Evidence: 'tacacs server ACME-TEAM-TACACS-01' uses a reversible Type 7 key; Type 6 encryption ('key config-key password-encrypt' + 'key 6 <key>') is required.; 'tacacs server ACME-TEAM-TACACS-02' uses a reversible Type 7 key; Type 6 encryption ('key config-key password-encrypt' + 'key 6 <key>') is required.; TACACS group name 'ACME-TEAM-TACACS' does not match the corporate group 'ACME_TACACS_SERVER_GROUP'.; No 'ip tacacs source-interface' configured under the TACACS server group.

Remediation Command:
```
aaa new-model
! Repeat the following 'tacacs server' block for each TACACS+ server.
tacacs server <tacacs_server_name>
 address ipv4 <tacacs_server_address>
 key 6 <tacacs_key>
 timeout <tacacs_timeout>
aaa group server tacacs+ <tacacs_group_name>
 server name <tacacs_server_name>
 ip tacacs source-interface <source_interface>
```

Operator Inputs Required: `<source_interface>`, `<tacacs_group_name>`, `<tacacs_key>`, `<tacacs_server_address>`, `<tacacs_server_name>`, `<tacacs_timeout>`
Owner: Network Security Team
Target Remediation Date: 2026-09-10 (<= 15 days, or next maintenance window)

### [control_00014] VTY Lines — HIGH

Status: NON-COMPLIANT
Reference: VibeCoding controls.yaml v6f92236

Risk Statement: Open VTY/Console sessions without timeouts can be hijacked.
Evidence: 'line con 0': 'login local' is missing.; 'line con 0': 'exec-timeout' is missing.; 'line vty 0 4': 'login local' is missing.; ACL 'VTY-OPEN' bound to VTY lines is permissive instead of restrictive: permit tcp any any eq 22; permit tcp any any eq telnet; 'line vty 5 15': 'login local' is missing.

Remediation Command:
```
line con 0
 password <console_password>
 login local
 exec-timeout <minutes> <seconds>
 logging synchronous
 exit
line vty <start_line_number> <end_line_number>
 access-class <vty_acl_name> in
 password <vty_password>
 login local
 exec-timeout <minutes> <seconds>
 transport input <allowed_protocols>
 logging synchronous
 exit
```

Operator Inputs Required: `<allowed_protocols>`, `<console_password>`, `<end_line_number>`, `<minutes>`, `<seconds>`, `<start_line_number>`, `<vty_acl_name>`, `<vty_password>`
Owner: Network Security Team
Target Remediation Date: 2026-09-10 (<= 15 days, or next maintenance window)

### [control_00009] NTP — MEDIUM

Status: NON-COMPLIANT
Reference: VibeCoding controls.yaml v6f92236

Risk Statement: Drifting clocks lead to inaccurate log timestamps, making forensic analysis and event correlation during a security incident nearly impossible.
Evidence: 'prefer' keyword is missing on the primary NTP server.; NTP authentication is not configured ('ntp authenticate' / 'ntp authentication-key' / 'ntp trusted-key' missing).

```

ntp trusted-key <ntp_key_id>
ntp authenticate
ntp server <ntp_ip_address> prefer
ntp server <secondary_ntp_ip_address>
```

Operator Inputs Required: `<ntp_ip_address>`, `<ntp_key_id>`, `<ntp_key_value>`, `<secondary_ntp_ip_address>`
Owner: Network Security Team
